# Implementasi feed dan koneksi sosial

1. Ambil RSS di Go, cache 30 menit dan berikan sumber, waktu, kategori, dan bukti tren.
2. Ganti koleksi contoh React dengan API. Pertahankan snapshot artikel dalam draft.
3. OAuth resmi dengan state sekali pakai, token di server, callback terdaftar, dan status koneksi yang sesuai hasil OAuth.
4. Gunakan video MP4 asli untuk review dan publikasi. Uji build dan feed. Uji login live memerlukan aplikasi provider milik pengguna.
